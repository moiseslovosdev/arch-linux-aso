01 / Introducción

¿Qué es Arch Linux?

Arch Linux es una distribución GNU/Linux de propósito general, independiente y de actualización continua (rolling release). Se caracteriza por ofrecer una base mínima que el usuario puede ampliar según sus necesidades.

Es popular entre estudiantes, desarrolladores y administradores que desean aprender cómo funciona su sistema operativo.

02 / Ventajas

Características principales

Arch Linux apuesta por la simplicidad técnica, el control y la documentación.

01 — ACTUALIZACIONES

Rolling release

Recibe actualizaciones continuas de paquetes, sin depender de grandes saltos entre versiones.

02 — PAQUETES

03 / Primeros pasos

Proceso general de instalación

Esta es una visión introductoria; los comandos y particiones exactos dependen del equipo. Consultá siempre la guía oficial antes de instalar.

Preparar el medio de instalación

Descargá la ISO oficial y prepará una memoria USB de arranque. Respaldá tus archivos antes de modificar discos.

Conectarte y preparar el almacenamiento

Verificá la conexión a Internet, el modo de arranque UEFI o BIOS y el esquema de particiones apropiado.

Instalar el sistema base

Instalá los paquetes esenciales, configurá el sistema, el usuario y el gestor de arranque siguiendo la documentación.

Personalizar y mantener

Configurá la red, el entorno gráfico y las aplicaciones. Mantené el sistema actualizado y revisá los avisos importantes.

Documentación oficial: ArchWiki — Installation guide.
04 / Soporte

Problemas frecuentes y soluciones

Algunas situaciones habituales y primeros pasos de diagnóstico.

PAQUETES

Fallan las actualizaciones

Comprobá Internet y los mensajes de pacman. Actualizá el sistema completo con sudo pacman -Syu; evitá las actualizaciones parciales.

RED

No hay conexión a Internet

Verificá el estado de la interfaz y del servicio de red con ip a y systemctl status NetworkManager, si utilizás NetworkManager.

ARRANQUE

El sistema no inicia

Revisá los mensajes de error, el gestor de arranque y las particiones. Desde un USB de rescate puede ser posible reparar la instalación.

SERVICIOS

Un servicio no funciona

Consultá systemctl status nombre-servicio y los registros con journalctl -u nombre-servicio para identificar la causa.

Consejo: antes de ejecutar comandos de reparación, entendé qué modifican y respaldá la información importante.
